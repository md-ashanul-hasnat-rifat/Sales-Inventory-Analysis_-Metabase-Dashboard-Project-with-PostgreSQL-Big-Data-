# Sales-Inventory-Analysis_-Metabase-Dashboard-Project-with-PostgreSQL-Big-Data-
## Metabase Dashboard Project with 
PostgreSQL (Big Data) 
It’s time for my capstone project!  
This final assignment will test my SQL skills, Metabase dashboarding expertise, and your ability to 
generate insights from real-world retail business data. 
I will be working with the Mexico Toy Sales & Inventory Dataset, which contains products, stores, 
daily sales, and stock levels for a fictional toy store chain operating across Mexico. 
Let’s turn my learning into a portfolio-ready BI project!  
## Dataset Description: 
You are provided with four interconnected tables: 
● Products 
● Stores 
● Sales 
● Inventory 
## Business questions:  
 Profitability 
● Which categories drive the most profit? 
● Which products have the highest margin? 
● Which stores generate the most revenue? 
 ## Store Performance 
● Which cities sell the most units? 
● Which stores underperform? 
 Seasonality & Trends 
● Monthly or weekly sales trends 
● Products with seasonal spikes 
 ## Inventory & Stock-Out Risk 
● Any store running out of high-demand SKUs? 
● Total value of inventory tied up 
● Products needing urgent restocking
